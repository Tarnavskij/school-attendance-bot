📥 Импорт учеников

Загрузить Excel-файл с учениками

Отмена

Формат: .xlsx, поля: Фамилия, Имя, Отчество, Дата рождения, Пол, Учебный год, Параллель, Буква

📖 Как получить файл из АСОД

  1. {{ step }}
    Перейдите на сайт АСОД
    https://asod.edu.by/Main
  2. {{ step }}
    Перейдите на вкладку «Учащиеся»
    В верхнем меню выберите раздел «Учащиеся».
  3. {{ step }}
    Выберите «Выборка по учащимся»
    В левом меню найдите пункт «Выборка по учащимся» и кликните.
  4. {{ step }}
    В левом окне «Свойства» отметьте «Учебный год»
    Поставьте галочку напротив поля «Учебный год».
  5. {{ step }}
    В правом окне «Условия построения выборки» настройте фильтр
    В поле «Учебный год» выберите «Равно» и укажите текущий учебный год (например, 2026-2027).
  6. {{ step }}
    Нажмите кнопку «Далее»
    Переход к выбору полей для отчёта.
  7. {{ step }}
    Отметьте необходимые поля
    Поставьте галочки напротив:
    • ✅ Первичная информация (Фамилия, Имя, Отчество, дата рождения, пол)
    • ✅ Класс (Учебный год, параллель, буква класса)
  8. {{ step }}
    Нажмите кнопку «Сформировать»
    Система сгенерирует отчёт.
  9. {{ step }}
    Нажмите на ссылку «Экспортировать отчёт в Excel»
    Файл будет сохранён на вашем компьютере.
  10. {{ step }}
    Вернитесь в веб-панель и загрузите файл
    На этой странице нажмите «Выбрать файл», укажите скачанный .xlsx и нажмите «Загрузить и импортировать».
  11. {{ step }}
    Дождитесь результатов импорта
    После загрузки вы увидите статистику: добавлено учеников, пропущено дубликатов, создано классов.

💡 Важно: Файл должен быть в формате .xlsx и содержать столбцы: Фамилия, Имя, Отчество, Дата рождения, Пол, Учебный год, Параллель, Буква. Остальные столбцы будут проигнорированы.
